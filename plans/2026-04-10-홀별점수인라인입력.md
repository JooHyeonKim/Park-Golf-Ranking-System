# 홀별 점수 버튼 → 모달 입력 기능 계획

## Context
점수 입력 화면(ScoreTable)에서 A/B/C/D 코스 점수 칸 옆에 버튼 하나를 추가.
버튼 클릭 시 모달이 열려 A1~A9 홀별 입력 가능.
입력한 합산값이 자동으로 해당 코스 합계(scoreA 등)에 반영.
백카운트도 동일 `detailScores` 필드를 그대로 사용하므로 자동 연동.

## 수정 파일 2개

### 1. `src/components/score/DetailScoreModal.jsx`
기존 백카운트 모달을 확장해서 재사용.

**변경사항**:

#### a) props 추가
```js
// initialCourse: 버튼을 누른 코스로 모달 열릴 때 해당 탭 자동 선택
// onSave 시 scoreA~F 합계도 함께 전달
export default function DetailScoreModal({ player, holeCount, onSave, onClose, readOnly, initialCourse })
```

#### b) initialCourse 반영
```js
const [activeCourse, setActiveCourse] = useState(initialCourse || courses[0]);
```

#### c) handleSave 수정 — 코스별 합계 자동 계산 후 함께 저장
```js
const handleSave = () => {
  const scoreUpdates = {};
  ['A','B','C','D','E','F'].forEach(c => {
    let sum = null;
    for (let h = 1; h <= 9; h++) {
      const v = scores[`${c}${h}`];
      if (v != null) { sum = (sum ?? 0) + v; }
    }
    if (sum !== null) scoreUpdates[`score${c}`] = sum;
  });
  onSave(player.id, { detailScores: scores, ...scoreUpdates });
  onClose();
};
```
→ 홀별 입력이 있는 코스의 합계만 자동 갱신, 없는 코스는 건드리지 않음.

### 2. `src/components/score/ScoreTable.jsx`
기존 DetailScoreModal 사용처가 이미 있으므로 확장 최소화.

#### a) 코스 점수 셀에 버튼 추가
각 코스 점수 `<input>` 렌더링 부분을 감싸는 컨테이너에 작은 버튼 추가:
```jsx
<div className="flex items-center gap-0.5">
  <input ... /> {/* 기존 scoreA 입력 */}
  <button
    onClick={() => setDetailModalPlayer({ player, initialCourse: 'A' })}
    className="text-gray-400 hover:text-blue-500 p-0.5 rounded transition-colors"
    title="홀별 점수 입력"
  >
    {/* 작은 격자 아이콘 (≡ 또는 grid 느낌) */}
    <svg className="w-3.5 h-3.5" fill="none" viewBox="0 0 24 24" stroke="currentColor">
      <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2}
        d="M4 6h16M4 10h16M4 14h16M4 18h16" />
    </svg>
  </button>
</div>
```

#### b) detailModalPlayer state 구조 확장
현재: `detailModalPlayer: player | null`
변경: `detailModalPlayer: { player, initialCourse } | null`

```js
// 기존 DetailScoreModal 호출부 수정
{detailModalPlayer && (
  <DetailScoreModal
    player={detailModalPlayer.player}
    holeCount={tournament.holeCount}
    initialCourse={detailModalPlayer.initialCourse}
    onSave={(playerId, updates) => onUpdatePlayer(tournament.id, playerId, updates)}
    onClose={() => setDetailModalPlayer(null)}
  />
)}
```

#### c) 기존 백카운트 버튼에서 모달 열기 방식 유지
백카운트용으로 열 때는 `initialCourse` 없이 열면 첫 코스(A) 자동 선택.
